## 2. 핵심 개념 및 용어 정리

### 핵심 개념

| 개념 | 설명 |
|------|------|
| **AI 네이티브 (AI Native)** | AI를 도구가 아닌 팀원처럼 대하며, AI와 자연스럽게 협업하는 사람 |
| **명시적 프롬프트 (Explicit Prompt)** | 암묵적인 배경지식이나 맥락을 명확하게 문서화하여 AI에게 전달하는 방식 |
| **에이전틱 AI (Agentic AI)** | 단순히 명령을 따르는 것을 넘어, 주도적으로 문제를 해결하고 제안하는 AI |
| **생각의 외부화 (Externalization of Thought)** | 머릿속에만 있는 아이디어를 구체적인 형태로 드러내는 과정 |
| **반복적 리파인먼트 (Iterative Refinement)** | AI와의 대화를 통해 지속적으로 결과물을 개선해 나가는 프로세스 |

### 핵심 용어

| 용어 | 설명 |
|------|------|
| **D.School (d.school)** | 스탠포드 대학교의 디자인 사고 연구소로, 혁신과 창의성 교육의 중심지 |
| **프롬프트 엔지니어링** | AI에게 원하는 결과를 얻기 위해 효과적인 지시문을 작성하는 기술 |
| **컨텍스트 윈도우** | AI가 한 번에 처리할 수 있는 정보의 양과 범위 |
| **Few-shot Learning** | AI에게 몇 가지 예시를 제공하여 원하는 출력 패턴을 학습시키는 방법 |
| **Chain of Thought** | AI에게 단계별로 생각하도록 유도하여 더 정확한 결과를 얻는 기법 |

## 3. 핵심 내용 요약

### 3.1 AI를 팀원처럼 대하기

제레미 어틀리 교수는 AI를 "도구"가 아닌 "팀원"으로 대하는 관점의 전환이 핵심이라고 강조합니다.

**도구로서의 AI vs 팀원으로서의 AI**
- **도구**: 명령 → 실행 → 결과 (일회성)
- **팀원**: 대화 → 협업 → 반복 개선 → 최적화 (지속적)

AI를 팀원처럼 대할 때:
- 더 많은 맥락을 제공할 수록 더 나은 결과를 얻음
- 피드백을 주고받으며 결과물을 함께 다듬어 감
- 창의적 문제 해결에서 시너지 효과 발생

### 3.2 명시적 프롬프트 작성법

**핵심 원칙: "영수증처럼 구체화하라"**

내 머릿속에만 있는 배경지식, 목표, 가이드라인을 명시적(Explicit)으로 전달해야 합니다.

**효과적인 프롬프트의 4요소:**
1. **목표 (Goal)**: 무엇을 달성하고 싶은가?
2. **배경 (Context)**: 어떤 상황에서 사용되는가?
3. **제약조건 (Constraints)**: 어떤 한계나 규칙이 있는가?
4. **출력 형식 (Format)**: 어떤 형태로 받고 싶은가?

**예시:**
```
❌ 나쁜 예: "마케팅 전략 짜줘"

✅ 좋은 예: 
"우리는 25-35세 직장인을 대상으로 하는 
구독형 스낵 박스 서비스를 론칭하려고 합니다.
월간 구독료는 3만원이며, 
경쟁사는 OO, OO입니다.
디지털 마케팅 중심의 3개월 론칭 전략을 
월별 실행 계획표 형식으로 제안해주세요."
```

### 3.3 생산성 10배 높이는 실전 전략

**전략 1: 아이디어 발산 → 수렴 → 실행의 반복**
- AI와 함께 다양한 아이디어를 폭넓게 생성 (Diverge)
- 함께 평가하고 최적의 방향을 선택 (Converge)
- 선택된 방향으로 구체적인 실행 계획 수립 (Execute)

**전략 2: 롤 플레이잉 활용**
- AI에게 특정 전문가나 페르소나를 부여
- "너는 20년 경력의 UX 디자이너야"와 같은 설정
- 해당 관점에서의 피드백과 제안을 받음

**전략 3: 멀티모달 활용**
- 텍스트만이 아닌 이미지, 코드, 데이터 등 다양한 형태로 소통
- 시각적 자료를 활용한 더 풍부한 협업 가능

**전략 4: 템플릿화와 자동화**
- 반복적인 작업은 프롬프트 템플릿으로 저장
- 워크플로우의 특정 단계를 AI에 위임
- 인간은 전략적 판단에 집중

### 3.4 창의력과 AI의 시너지

**AI는 창의성을 대체하지 않고 증폭시킨다**

- AI는 "평균적인" 아이디어를 빠르게 생성
- 인간의 역할은 그 위에 독특한 통찰과 가치를 더하는 것
- "AI가 생각하지 못하는 방향"을 제시하는 것이 핵심

**창의적 문제 해결 프로세스:**
1. 문제 정의 (AI가 도와줄 수 있음)
2. 다양한 관점에서의 탐색 (AI + 인간 협업)
3. 독창적 해결책 도출 (인간의 강점)
4. 구체화 및 실행 (AI가 도와줄 수 있음)

## 4. 인사이트 및 느낀 점

### 핵심 인사이트

1. **"AI에게 말하는 방식이 곧 생각하는 방식"**
   - 명확하게 프롬프트를 작성하려면 자신의 생각을 먼저 정리해야 함
   - AI와의 대화가 자기 성찰과 사고 정리의 과정이 됨

2. **"완벽한 프롬프트보다 지속적인 대화가 중요"**
   - 처음부터 완벽할 필요 없음
   - 대화를 통해 점진적으로 결과물을 개선하는 것이 핵심

3. **"AI는 대체재가 아닌 보완재"**
   - AI가 할 수 없는 것(독창성, 감성, 윤리적 판단)에 인간이 집중
   - 반복적·체계적 작업은 AI에 위임하여 고차원적 업무에 집중

4. **"생산성의 정의 자체가 변화하고 있음"**
   - 더 많은 일을 하는 것이 아닌, 더 가치 있는 일에 집중
   - AI를 활용한 "선별과 집중"의 능력이 핵심 역량

### 실생활 적용

**개인 업무에 적용하기:**
- 매일 아침 AI와 함께 당일 업무 우선순위 정리
- 복잡한 이메일 작성 시 AI에게 초안을 받아 수정
- 새로운 주제 학습 시 AI에게 개념 설명과 질문 리스트를 요청

**팀 협업에 적용하기:**
- 브레인스토밍 세션에서 AI를 아이디어 발굴 파트너로 활용
- 회의록 작성과 액션 아이템 도출을 AI에 위임
- 프로젝트 기획 단계에서 AI와 시나리오 탐색

**학습과 성장에 적용하기:**
- 새로운 분야 학습 시 AI에게 커리큘럼 설계를 요청
- 학습 내용을 AI에게 설명하며 피드백 받기 (페륨 효과)
- AI와의 토론을 통해 사고의 깊이를 더하기

## 6. 복습 퀴즈

### 문제 1
**Q:** AI를 도구가 아닌 팀원으로 대하는 것의 핵심 차이점은 무엇인가요?

<details>
<summary>정답 보기</summary>

**A:** 도구로서의 AI는 일회성 명령-실행 관계인 반면, 팀원으로서의 AI는 지속적인 대화와 협업을 통해 결과물을 함께 개선해 나가는 관계입니다. 팀원으로 대할 때 더 많은 맥락을 제공하고 피드백을 주고받으며 창의적 시너지를 얻을 수 있습니다.

</details>

### 문제 2
**Q:** "명시적 프롬프트" 작성의 핵심 원칙은 무엇이며, 4가지 핵심 요소는?

<details>
<summary>정답 보기</summary>

**A:** 핵심 원칙은 "영수증처럼 구체화하라"는 것입니다. 머릿속에만 있는 배경지식과 맥락을 명확히 드러내야 합니다.

4가지 핵심 요소:
1. **목표(Goal)**: 달성하고자 하는 것
2. **배경(Context)**: 사용 상황과 환경
3. **제약조건(Constraints)**: 한계와 규칙
4. **출력 형식(Format)**: 원하는 결과물의 형태

</details>

### 문제 3
**Q:** AI와의 협업에서 인간의 핵심 역할은 무엇인가요?

<details>
<summary>정답 보기</summary>

**A:** 인간의 핵심 역할은 다음과 같습니다:
- 독창적 통찰과 가치 제안
- 윤리적 판단과 가치관 반영
- 전략적 방향 설정과 우선순위 결정
- AI가 생각하지 못하는 "틀 밖의" 관점 제시
- 감성적 공감과 인간 중심적 접근

AI는 평균적인 아이디어를 빠르게 생성하지만, 인간이 그 위에 독특한 가치를 더할 때 진정한 시너지가 발생합니다.

</details>

### 문제 4
**Q:** 생산성 10배 향상을 위한 4가지 실전 전략은?

<details>
<summary>정답 보기</summary>

**A:** 
1. **아이디어 발산 → 수렴 → 실행의 반복**: AI와 함께 다양한 아이디어를 생성하고 평가하여 최적의 방향을 선택하고 실행

2. **롤 플레이잉 활용**: AI에게 특정 전문가나 페르소나를 부여하여 해당 관점의 피드백 받기

3. **멀티모달 활용**: 텍스트뿐만 아니라 이미지, 코드, 데이터 등 다양한 형태로 소통

4. **템플릿화와 자동화**: 반복적인 작업은 프롬프트 템플릿으로 저장하고 워크플로우의 특정 단계를 AI에 위임

</details>

### 문제 5
**Q:** AI 시대에 "생산성"의 의미가 어떻게 변화하고 있나요?

<details>
<summary>정답 보기</summary>

**A:** AI 시대의 생산성은 "더 많은 일을 하는 것"에서 "더 가치 있는 일에 집중하는 것"으로 변화하고 있습니다. AI를 활용한 "선별과 집중"의 능력이 핵심 역량이 되며, 반복적·체계적 작업은 AI에 위임하고 인간은 전략적 판단과 창의적 문제 해결에 집중하는 것이 새로운 생산성의 정의입니다.

</details>
