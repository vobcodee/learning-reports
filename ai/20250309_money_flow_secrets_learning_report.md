## 2. 핵심 개념 및 용어 정리

### 핵심 개념

| 개념 | 설명 |
|------|------|
| **손실회피 편향 (Loss Aversion)** | 100만 원을 벌 때의 기쁨보다 100만 원을 잃을 때의 고통이 2배 이상 크다는 심리적 현상. 이로 인해 손실 상황에서 위험을 감수하려는 경향이 생김 |
| **처분 효과 (Disposition Effect)** | 수익이 난 주식은 빨리 팔고, 손실이 난 주식은 오래 보유하는 경향. 이는 손실회피 편향에서 비롯됨 |
| **전망 이론 (Prospect Theory)** | 2002년 노벨 경제학상 수상자인 다니엘 칸먼의 이론. 이익 상황에서는 위험 회피, 손실 상황에서는 위험 선호하는 경향을 설명 |
| **실질 금리 (Real Interest Rate)** | 명목 금리에서 인플레이션을 뺀 값. 예: 명목 금리 3.5% - 인플레이션 2% = 실질 금리 1.5% |
| **레버리지 ETF** | 기초 지수의 2배, 3배 수익률을 추구하는 ETF. 고수익 가능성과 함께 고위험도 수반 |
| **동학개미 운용** | 2020년 코로나19로 증시 폭락 시 외국인이 팔자 개인 투자자들이 대거 매수한 현상 |
